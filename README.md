# Prof. Rodrigo Campos

Site pessoal de apresentação, publicado com o GitHub Pages.

🔗 **Acesse:** https://profrodrigocampos.github.io

## Sobre o projeto

Página de apresentação profissional com formação, áreas de atuação, projetos de infraestrutura e certificações. O visual escuro, com uma topologia de rede animada no topo, faz referência às áreas de redes de computadores e arquitetura e organização de computadores.

## Tecnologias

- **HTML5**: estrutura e conteúdo da página
- **CSS3**: layout, cores e responsividade (variáveis CSS, Grid e Flexbox)
- **JavaScript**: animação da topologia de rede com a API Canvas
- **GitHub Pages**: hospedagem gratuita do site

Não usa frameworks nem bibliotecas externas, apenas as fontes do Google Fonts.

## Estrutura

```
├── index.html      # conteúdo da página
├── css/
│   └── style.css   # estilos
└── js/
    └── main.js     # animação e interações
```

## Como rodar no seu computador

1. Baixe o projeto em **Code → Download ZIP**
2. Extraia o arquivo
3. Abra o `index.html` no navegador

## Como publicar o seu próprio site

1. Crie um repositório público chamado `seu-usuario.github.io`
2. Envie os arquivos com o `index.html` na raiz do repositório (não dentro de uma pasta)
3. Aguarde alguns minutos e acesse `https://seu-usuario.github.io`
